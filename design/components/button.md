# Button

## Intent

Buttons trigger an immediate action. Use one primary button for the most important action in a region; use secondary or ghost buttons for supporting actions.

## Variants

- **Primary:** Ink background with white text; used for the main commitment.
- **Secondary:** Quiet Surface background with an outlined edge.
- **Ghost:** Transparent background for low-emphasis actions.
- **Icon:** A square, circular control with an accessible name.

## States

All buttons have hover, active, disabled, and keyboard-focus states. Disabled buttons reduce opacity and do not respond to the pointer.

## Accessibility

Use visible text whenever space permits. Icon-only buttons require an `aria-label`. Never use a button for navigation.
